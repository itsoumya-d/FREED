# FREED Passage design language

Revised after the user rejected the flat mint implementation on 2026-10-03. The visual priority is an original premium identity across the whole application, while preserving recovery data, native controls, languages, pricing and protection authority.

## Reference grammar

Fresh Appllama study: Opal Today (1497465230/oth_gbmxf), Distracting Apps (oth_90b92), active timers/rewards/settings, and QUITTR's available onboarding/welcome/paywall images. Opal contributes focused control hierarchy, disciplined typography and dimensional material. QUITTR contributes a personal progression narrative and a memorable visual world. Its actual product screens are unavailable in the library and are not assumed verified. No competitor pixels, imagery, watermark or medical claims are reused.

## Original identity

Warm chalk, deep umber and burnished copper. One warm neutral family; one copper action accent; amber/red only for functional warning/error states. Light canvas #F7F1E8, dark canvas #211D19. Native type, lighter display counters, body17, subdued footnotes, tabular numeric data. Screen gutters24, four-point spacing, continuous corners: actions16, primary cards24/28, grouped controls20, fields16. Native stack/tab behavior stays intact.

The recurring visual is an original ceramic passage with a copper path and suspended disc. Breathing uses concentric ceramic rings in the same material/lighting. Both assets were generated with the built-in ImageGen tool and copied to assets/artwork; master images remain alongside optimized PNGs. The geometric passage/F symbol remains code-native and will be recolored to this palette. No generated words or interface text are baked into the art.

## Motion

Native navigation and keyboard transitions; 120ms press feedback, 200ms state changes, 260ms detail reveals. The illustration responds to press position with bounded worklet tilt and a spring return; scrolling stays native. Data never tilts. Spatial artwork movement is disabled for Reduce Motion and hidden/backgrounded screens. Breathing expansion follows the real exercise phase rather than a decorative loop. Milestone reveals happen on earned events, not every visit.

## Screen grammar

Today: compact native title, quiet date/protection context, one sculptural recorded-streak hero, one clear next action, grouped practices and tools. The primary action must appear in the initial normal-font phone viewport. Progress starts with real history; estimates stay secondary. Shield has a concise overview and focused native detail routes. Profile uses calm grouped sections and readable forms. Onboarding, paywall, tools and legal views share the same surfaces, colors, control geometry and language behavior.

## Acceptance

Inspect installed screens in both themes, all ten languages, Arabic RTL, small screens and large text. Record full interactions and motion; screenshot quality does not establish physical release performance. The previous mint screenshots and test run remain baseline evidence, not final visual approval. The 64-surface review matrix remains active.
