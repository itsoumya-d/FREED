# Internal candidate test guide — FREED Momentum

Candidate source: daily-usability-v6-comfort. Intended iOS version1.0/build3, internal-testflight channel, Google sample rewarded units. Verify the actual processed TestFlight build before installation; an archive or upload attempt is not installability evidence.

## First setup

Choose language/appearance, connect Apple/Google/email, retain quiz answers, select websites/apps, then grant only relevant permissions. Declining a permission must leave that protection layer visibly off and keep basic help accessible. Check English/Hindi/Korean/Arabic and both themes first, with large text and keyboard/back behavior. A genuine email verification-later state is supported.

## Protection

On the device, enable supported adult website protection and selected whole-app guards. Inspect configured/OS-enabled/observed health separately. Test the safe Cloudflare category hostname `nudity.testcategory.com` and ordinary `example.com`; record the network, OS, native state and actual browsing outcome. Test selected and unselected apps, schedules, daily thresholds, restart, permission loss, settings return, network changes and relock after a target-specific break. Cloudflare Families requires no website zone, Worker or dashboard rule. DNS cannot inspect HTTPS Shorts paths or redirect a webpage into FREED. Native Shorts/Reels remain outside this public release.

## A short daily interruption

Open recovery through the supported native barrier/handoff. Free users explicitly choose Watch ad and continue, Go Pro or Basic help. Test SDK reward, skip, unavailable and consent cases; neither ad viewing nor challenge completion removes adult-domain protection. Premium/review access skips ads, and unknown access cannot trigger an ad. Choose Breathe/Find something/Move, pause/background/resume, replace within the same category and save once. Replacement must retain the earned session. Confirm exactly one durable completion appears in Today/Progress. Photo targets remain unavailable until their provider/model held-out accuracy receipt passes; camera hardware alone is insufficient.

## Quiet and offline use

Use gentle breathing at a comfortable pace, enable/disable phase sounds, pause/background and test headphone/audio interruptions. Sounds remain optional. Save a private journal draft, interrupt/reopen, edit an earlier entry and verify Today receives no invented activity. Cloud chat defaults off; enabling it needs explained consent. Optional prior context includes only recent user-authored messages. Verify disabled/unavailable/quota/budget/cancel states and that account switching cannot transmit or display the prior owner's request. A real signed App Check/cloud reply still needs evidence before server rollout.

## Membership and weekly review

Confirm store-provided localized monthly/yearly prices; missing metadata must disable checkout rather than show a purchasable invented price. Complete sandbox purchase, cancel checkout, restore and owner-change cases. Test cancellation through paid expiry, renewal, grace/hold, expiry and revocation. Recorded recovery history and baseline protection remain. Progress must explain recorded actions and what helped, without rewarding blocked attempts or ad views. Verify encrypted backup/restore, owner isolation and visible retryable deletion failure.

For each scenario record source snapshot, binarySHA256, device/OS, account/entitlement state, outcome and recording/log artifact. Preserve failures and blocked scenarios.
