## Binding constraints

- New user: Get started → five questions → factual starter-plan summary → required real Apple/Google/email account → one membership offer → Subscribe or Continue with Free → Home.
- Existing user: I have an account → sign-in → restore account/membership → Home; show the offer once per account/offer version if not acknowledged. Returning authenticated users open Home without another onboarding cycle. Anonymous identity and saved email are never authentication proof.
- Today, Protect, Progress, Profile remain native peer tabs. All features is one tap from Today, searchable, and states purpose, actual availability and next action.
- Public shared coverage: adult-domain protection, whole-app guards, recovery tools. Selective Shorts/Reels stays off on both. Adult sites never unlock from ads, purchases or challenge completion.
- Guided offer: paid Start challenge; free Go Pro / explicitly opt-in Watch one ad for one guided session; safe decline and basic Help now remain accessible. Unknown membership never requests ads.
- Only a genuine native SDK reward acknowledgment grants one owned session; no mock/fallback grant, permanent Premium, recorded practice, native unlock, private targeting context, or repeat ad after restart/resume.
- Completion/helpfulness/app-break authority remain separate. Individual app/package scopes only; explicit break request + verified receipt + current matching native acknowledgment. Standalone tools never grant access. Preserve configured duration (new default ten minutes).
- Website/app setup are independent. Native before-use, daily-limit and scheduled modes report actual scope and state. Legacy absent mode hydrates daily-limit; new profiles default before-use without any selected targets. Passive writes never release reset latch.
- Preserve Expo55/RN0.83.6, product IDs, equal monthly/yearly benefits, no trial, ten locales, stored date keys, native materials/navigation and existing artwork. No new illustration collection.
- Preserve four externally frozen privacy modules: firebase-feature-runtime.ts, ai-coach.ts, challenge-generator.ts, retention-orchestrator.ts. No automatic remote AI callbacks or health/context transmission. Remote AI requires a separate explicit consent and verified service path.
- Preserve dirty shared codex checkout and other edits. No stash/reset/whole-file restoration, broad source-mutating gate, commit, publish or new permission/credential action from workers. Broad gates/builds use isolated snapshots. Source proof is separate from physical/store/motion evidence.
