## Install Troubleshooting

| Failure case | Recovery action | Evidence |
| --- | --- | --- |
| Phone cannot open the QR target | Keep the Android phone and this Mac on the same Wi-Fi, turn off phone VPN or cellular-only browsing, then try the alternate LAN URL shown on the page. | Live check still passes from the Mac and the phone screenshot shows the attempted LAN URL. |
| Browser blocks the APK download | Use Chrome or the default browser, keep the filename unchanged, accept the one-time Android download warning, and do not rename the APK. | Downloaded file name and SHA-256 match the handoff. |
| Install unknown apps prompt appears | Tap Settings, enable Allow from this source for the browser that downloaded the APK, press Back, and resume the same install. | Install QA notes show the browser-specific install-from-this-source permission was granted by the user. |
| App not installed or package conflicts | Uninstall the previous local FREED build for app.freed.recovery, then install this APK again from the completed download. | Install QA report shows app.freed.recovery was freshly installed and launched. |
| Install fails because storage is low | Free storage, delete partial FREED APK downloads, download again from the QR target, and verify the hash before install evidence is captured. | Install QA report uses the current APK hash from this handoff. |

## Recovery Notifications

On Android 13+, FREED asks for the runtime notification prompt in-app first, then opens Android app notification settings only if the permission remains denied. This is optional for activation but required for DNS Guard visible recovery-handoff evidence.

| Check | Expected result | Evidence |

| Android 13+ runtime notification prompt | FREED asks in-app first from the optional recovery-notification row. | `docs/validation/artifacts/android-download-current/android-real-browser-capture/android-notification-permission-report.json` |
| Settings fallback only if denied | FREED opens Android app notification settings only after Android still reports notification permission denied. | `android.notificationSettingsFallbackOpenedIfDenied=true` |
| Native status after return | Profile/native status shows `androidNotificationPermissionRequired` and `androidNotificationPermissionGranted`. | Native status screenshot plus `android.notificationPermissionGranted=true` |
