Navigation model

Four destinations, always reachable. Nothing is more than one tap away, and the current destination is never ambiguous.

  • Today — the daily action surface. State, pledge, challenges.
  • Shield — protection status and controls. Configuration, not browsing.
  • Progress — longitudinal data. Read-only, no setup tasks.
  • Profile — account, reminders, accountability, data.

Adaptive behaviour

  • Compact (<600) — bottom tab bar, single column, 56px targets.
  • Medium (600–839) — same shell, wider cards, 4-up stat grid.
  • Expanded (≥840) — left nav rail, two-pane Today, no bottom bar.

Navigation is never hidden behind a menu in any size class. The rail replaces the bar rather than supplementing it.

Visual hierarchy

Every screen resolves in the same reading order: status → primary action → supporting data → configuration.

  • One primary CTA per screen, always tinted and always thumb-reachable.
  • Section titles at 20px/800 with a "View all" affordance at the same baseline.
  • Numbers carry the colour; labels stay neutral so they never compete.
  • Destructive actions are separated into their own card at the very bottom.

Call-to-action placement

  • Today → pledge banner sits above the fold, before the challenge list.
  • Shield → setup CTA lives inside the status card, so fixing a problem is adjacent to seeing it.
  • Profile → "Manage" is inline in the header; destructive actions are last.

Colour & accessibility

Mint Purple Peach Sky Red
  • Body text on canvas 8.1:1AAA
  • Secondary text on canvas 5.4:1AA
  • Accent on surface 4.9:1AA
  • Every status is colour plus icon plus label — never colour alone.

Light mode is not an inversion. Accents are re-derived to keep AA on light surfaces, and the high-contrast profile swaps in pure black/white with 3px borders.

Component set

18 components, one definition each. Screens compose them; they never restyle them.

  • Status: chip, banner, verdict, progress ring
  • Input: button (4 variants), icon button, switch, stepper, text field
  • Structure: card, list row, section header, app bar, tab bar / rail
  • Data: stat tile, bar chart, heatmap, week strip

Consistency rules

  • Radius ladder 12 / 18 / 24 / 32 — cards 24, controls pill, chips pill.
  • Spacing on a 4pt grid; page margin 20, section gap 24.
  • Minimum 44px touch target (48 on Android profile).
  • Focus ring 2px, offset 2px, always visible on keyboard nav.

Motion

Motion confirms cause and effect. It never decorates.

  • Fast 160ms — press, toggle, hover.
  • Base 240ms — panel entry, toast.
  • Slow 420ms — layout changes, viewport resize.
  • Easing cubic-bezier(.2,0,0,1); entrance from 8px below.

The Reduce motion toggle zeroes every duration to honour prefers-reduced-motion.
