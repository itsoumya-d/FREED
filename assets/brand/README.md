# FREED premium brand

The current mark is an original geometric F / open-passage vector, with a solid mint silhouette and native FREED wordmark. It replaces the earlier textured mark, preserved under previous/.

Canonical source: freed-symbol.svg. Monochrome and light variants are saved alongside it. Production PNG sources are rasterized from that vector; scripts/generate-brand-assets.js derives the platform icons and splash resources without prebuilding or replacing native extensions. platform-assets.json records output SHA-256 hashes.

PassageArtwork.tsx uses three original matte vector depth planes in the same palette. Assets were authored as code-native vectors; no competitor imagery is shipped. Visual and native-device verification remain separate from asset generation.
