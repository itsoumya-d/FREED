# FREED breathing cues

Original synthesized mono PCM audio, 24 kHz, 16-bit, 300 ms each. No third-party samples or voices.

- Inhale: rising 440–660 Hz tone.
- Exhale: falling 660–440 Hz tone.
- Hold: short steady 523.25 Hz tone.

The app supplies localized phase text. Sound is optional and follows the actual session phase, pause, focus and background state. It does not record a microphone or establish completion. Physical silent-mode, interruption and headphone behavior remains part of native release verification.
