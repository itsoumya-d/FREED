# Momentum breathing illustration

Source: [Breathing In Out by Lab](https://lottiefiles.com/free-animation/breathing-in-out-6tPIN1B5iM), downloaded 2026-10-03 from the asset URL exposed by that public page. Original dotLottie archive and extracted JSON are retained here.

`breathing-cadence.json` is a derivative under the same Lottie Simple License: one 950-frame cycle, all embedded English text/font layers removed, fill/stroke colors changed to Momentum coral. The app renders its own localized phase labels. Playback is controlled by actual elapsed active exercise time, with cancellation on pause/background/Reduce Motion. The artwork never grants completion or recovery credit.

The original cycles contain 200 frames of inhale, 350 of hold and 400 of exhale. The UI maps these graphic ranges onto the selected real cadence, including box breathing and two-stage sigh. Native renderer and motion verification are separate from this source transformation.
