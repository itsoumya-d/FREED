# 2026-09-08

## FREED core screens UI prototype

Built `design/freed-ui-prototype.html` — a self-contained interactive prototype of the four
root destinations (Today, Shield, Progress, Profile).

- Grounded in the real product: palette from `src/constants/design.ts` (bg #1B1929, mint
  #5ADF9E, purple #B898FF, peach #FF9B72) and semantic tokens from
  `design/freed.mobile.tokens.json`.
- Four destinations come from `src/design-system/navigation.ts` (`ROOT_DESTINATIONS`);
  screen copy taken from real strings in `src/features/freed-app.tsx`.
- Three size classes: compact <600 (bottom tab bar), medium 600-839 (wider grids),
  expanded >=840 (left nav rail replaces the bar, Today splits into two panes).
- Light theme is a re-derivation, not an inversion — accents darkened to hold AA on light
  surfaces. Separate high-contrast and reduced-motion profiles.
- 18 components, one definition each (card, list row, chip, switch, stepper, verdict,
  progress ring, bar chart, heatmap, week strip, stat tile, banner, 4 button variants).
- Interactions: tab switching with arrow-key nav, pledge state change, toggles, steppers,
  live URL classification, viewport/theme/contrast/motion switchers.

Verified: embedded JS passes `node --check`, HTML tags balanced (209/209 divs).
